# Lumio sign-up page (Bootstrap 5.3 + Vercel)

Static site: `index.html`, `css/style.css`, `js/script.js`. No build step needed.

## Deploy with GitHub (easiest)
1. Create a new GitHub repository and upload these files (keep `index.html` at the root).
2. Go to https://vercel.com/new and import the repository.
3. Framework Preset: **Other**. Leave Build Command and Output Directory empty. Click **Deploy**.

## Deploy with the Vercel CLI
```
npm i -g vercel
cd signup-app
vercel --prod
```
